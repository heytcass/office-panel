# Install

Physical install notes for the panel. Filled in during Phase 1 / Phase 4.

## Mounting location

Wall, hallway-side of the office door, facing approaching foot traffic. Not visible from inside the office.

## Power

Battery only — no wired power at the install location. Charge via USB-C as needed (low-battery alerts fire at 20% / 10% / 5% per SPEC §10).

## Wiring

Not applicable. The reTerminal E1002 ships as a sealed unit; there is no external wiring.
